# 崩坏星穹铁道抽卡蒙特卡洛模拟

本项目为崩坏星穹铁道铁道抽卡系统的蒙特卡洛模拟，以崩坏星穹铁道的原生抽卡机制进行模拟，并通过大量蒙特卡洛模拟来计算抽到目标角色和光锥所需抽数和资源数，并给出统计图。

该程序考虑到了未熄的星芒所带来的扰动，并以此重新计算所需资源数量。请注意：上述逻辑假设所有未熄的星芒均兑换成星轨专票。

> 本系统仅支持崩坏星穹铁道的抽卡模拟，除非明确其抽卡概率机制完全相同，请勿依据该系统进行原神、绝区零等其他游戏的抽卡模拟！

## 配置方式

需要先安装Poetry再运行本程序。请勿在本程序对应的虚拟环境中安装Poetry。具体安装方法可参考[Poetry安装方法（英语）](https://python-poetry.org/docs/)。

本程序要求使用Python 3.14或更高版本以实现完美运行，对于使用低版本Python的用户，恕不保证该程序的具体行为和稳定性。

安装Poetry后，通过

```shell
poetry install
```

可以安装所有的所需依赖。可通过

```shell
poetry config virtualenvs.in-project true
```

让Poetry仅在本项目的运行环境中建立的.venv目录中运行以实现项目依赖隔离。
本项目使用的脚本如下

```shell
poetry run monte-carlo  # 运行基本的蒙特卡洛模拟器，生成所需抽卡数频率分布直方图
```

## 规划

- [x] 抽数频数分布直方图
- [ ] 所需资源频数分布直方图
